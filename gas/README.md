# 結帳串接 Google 試算表：設定步驟

## 架構
```
網站結帳 ──POST(JSON)──▶ Google Apps Script 網頁應用程式 ──▶ Google 試算表
                         （驗證、以「商品」表重算金額、     ├ 訂單
                           產生訂單編號、寄通知信）          ├ 訂單明細
                                                             └ 商品（價格唯一來源）
```
- 前端只傳「商品 ID + 數量」，金額由 GAS 依「商品」工作表重算，無法被竄改。
- 訂單編號格式 `JZ20261116-0001`，由 GAS 加鎖產生，不會重複。
- 目前**沒有線上付款**；訂單進表後由店家聯絡顧客確認。

## 設定步驟（約 10 分鐘）
1. 建立一份新的 Google 試算表（名稱例如「餃酌訂單」）。
2. 上方選單：**擴充功能 → Apps Script**，把預設程式碼全部刪掉，貼上本資料夾的 `Code.gs`。
3. （選填）在程式最上方 `CONFIG.OWNER_EMAIL` 填入店家收件信箱，每筆新訂單就會寄通知信。
4. 上方函式下拉選 **setup**，按「執行」，依畫面授權。完成後試算表會多出「訂單」「訂單明細」「商品」三個工作表。
5. 右上角 **部署 → 新增部署作業 → 類型選「網頁應用程式」**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」，複製出現的**網頁應用程式網址**（結尾是 `/exec`）。
6. 把網址貼到網站的 `config.js` 的 `orderEndpoint`，推上 GitHub，或把網址傳給 Claude 代為設定。

## 日常維運
- **改價格／上下架商品**：直接改「商品」工作表（`上架` 欄填 TRUE 或 FALSE），不用改程式。網站顯示的價格是另外寫在 `index.html`，兩邊要一起改。
- **處理訂單**：在「訂單」表的 `狀態` 欄自行改成「已確認」「已完成」等。
- **改程式後**：Apps Script 需 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變。
- Gmail 寄信有每日額度（一般帳號約 100 封）；不想寄顧客確認信可把 `SEND_CUSTOMER_EMAIL` 設為 `false`。

## 測試
部署後在瀏覽器開啟網頁應用程式網址，看到 `{"ok":true,"service":"jiaozhuo-orders"}` 代表上線成功；再到網站下一筆測試訂單，確認試算表出現新列。
